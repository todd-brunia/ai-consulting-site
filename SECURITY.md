# Security Policy

## Report a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/todd-brunia/ai-consulting-site/security/advisories/new).
Do not open a public issue or pull request containing vulnerability details,
credentials, personal information, or exploit instructions.

Include the affected area, steps to reproduce, potential impact, and any known
mitigation. Todd will review the report and respond through the private
advisory. This project does not promise a specific response or remediation
timeline.

Private vulnerability reporting must remain enabled in the repository's
Security settings for this channel to work.
