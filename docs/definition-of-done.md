# Definition of Done

A website change is done when:

- The originating issue contains an approved plan and acceptance criteria.
- The implementation stays within the approved scope.
- Existing components and styles are reused where practical.
- Visitor-facing copy follows the product brief and content style guide.
- No unsupported marketing claim has been introduced.
- Lint, type checking, tests, and the production build pass.
- Relevant tests are added or updated.
- Keyboard use, semantics, focus visibility, and color contrast are considered.
- Desktop and narrow mobile layouts are reviewed.
- Visual changes include before-and-after screenshots or equivalent evidence.
- The PR links the issue and includes the Vercel preview URL.
- Known limitations and deferred work are recorded.
- A human reviews the code, copy, and preview and merges the PR.
- Production is verified after Vercel deploys the merged `main` branch.

AI may report that its work is ready for review, but it may not approve its own
plan, approve its visual output, merge the PR, or deploy directly.
